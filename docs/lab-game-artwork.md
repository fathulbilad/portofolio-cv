# Games gallery artwork

The gallery uses official promotional screenshots to illustrate the personal
game collection. These are third-party game images, separate from the original
generated Lab illustrations. Each featured image links to its source page.
Images were converted to WebP at quality 85, with a maximum width of 1600px
and no enlargement. Game notes in `lib/lab.ts` are editable draft copy.
