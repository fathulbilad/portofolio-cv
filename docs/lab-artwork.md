# Original Lab artwork

The illustrations below were created with the built-in image generation tool. The
artwork is original, illustrative imagery; game and album names in the starter
collection do not identify the generated artwork. The monochrome artwork is
tinted by the website's CSS. Images are encoded as WebP at quality 84, at a
maximum width of 1200px, preserving the generated composition.

The Games gallery now uses official game screenshots documented in
[the game artwork notes](lab-game-artwork.md). The original abstract Games
illustration below remains available as a separate asset.

## Saved assets and final prompts

### `public/lab/life.webp`

> A quiet editorial photograph for a personal website. Warm afternoon window light casts a simple rectangular shadow across an empty cream plaster wall with a narrow coral curtain at far right. Slight analog grain, tactile muted paper-like tones, peaceful, understated. Landscape 3:2, no people, objects, furniture, text, border or logos. This is one actual image asset, not a website mockup.

### `public/lab/games.webp`

> An original abstract game-world landscape artwork for a personal website. Ink black and warm ivory monochrome ONLY. Angular stone cliffs and sharp pathways lead toward a giant circular pale sun, spacious mysterious empty landscape, screen-print halftone shading, graphic high contrast, refined gritty printed texture, original environment, no recognizable game references. Landscape 3:2. No characters, people, text, symbols, logos, cards, frame or website UI. Mostly black with pale architectural planes and light negative space. This is one actual background artwork asset that will be tinted electric yellow by CSS.

### `public/lab/music.webp`

> An original abstract album-cover artwork for a personal website. Square composition. Flowing organic broad ink-black and ivory waves, asymmetrical rippling fluid fabric-like curves, subtle screen-printed halftone texture, very restrained two-color graphic composition, bold shapes with calm negative space. No record object, no people, no text, logos, border, website UI, or imitation of any real album. This is an actual image asset; ivory areas will be tinted cobalt blue by CSS.

### `public/lab/projects.webp`

> An original abstract sculpture artwork for a personal website. Ink-black space with a small architectural arrangement of intersecting folded ivory paper planes, geometric origami-like angular monoliths casting sharp graphic shadows. Mostly black, few softly glowing ivory edges, screen-print halftone grain. Landscape 3:2. No real buildings, identifiable objects, people, characters, text, symbols, frame, logos, website UI or borders. This is one actual artwork asset; pale planes will be tinted cyan by CSS.
